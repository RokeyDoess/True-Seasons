# Security reports

Report exploitable security problems privately through [GitHub's vulnerability reporting page](https://github.com/RokeyDoess/True-Seasons/security/advisories/new). Do not post exploit details in a public issue.

Include the affected version, server setup, reproduction steps and expected impact. Remove passwords, tokens and other private information from attachments.

Reports should identify whether the problem affects the latest prerelease. Older releases may need an update before a fix can be verified. There is no guaranteed response time.

Ordinary bugs, performance problems and setup questions belong in [Issues](https://github.com/RokeyDoess/True-Seasons/issues/new/choose).
