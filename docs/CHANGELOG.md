# Changelog

## 1.0.0

First stable release.

- Seasonal landscapes with colorful autumn trees and native winter snowfall. No resource pack or client mod required.
- Gradual snow cover and melting, with saved plants restored when their space remains suitable.
- Seasonal BlueMap colors and snow updates that resume after restarts.
- Configurable calendar, manual season controls and progress notifications.
- Small batches of terrain work, shared visual preparation and fewer unnecessary map renders.
- Cleanup to restore temporary changes before removing the plugin.
