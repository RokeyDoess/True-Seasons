# Planned features

- A gradual snowmelt transition when winter ends, reversing winter's opening snowstorm and optionally following players.
- Start region-by-region updates at the center of the map and spiral outward, finishing each region before moving to the next.
- More testing on large worlds, including busy servers and interrupted saves.
- Further reductions in startup time and memory use on large worlds.
- Distant Horizons support.

These features are still in development and are not included in 0.1.10.
