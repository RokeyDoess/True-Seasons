# Planned features

- Profile larger worlds and busy servers, reducing repeated work, memory use and unnecessary map renders.
- Expand recovery and cleanup testing, including interrupted saves and out-of-sequence season changes.
- Gradually introduce seasonal colors during the opening week of calendar seasons, with whole autumn trees changing at different times.
- Use orange for decorative autumn leaves and trees whose color cannot be resolved safely.
- Give a fixed third of suitable deciduous trees a spring blossom appearance, without changing saved leaves.
- Add sparse summer fireflies near water and sheltered vegetation, excluding oceans. No pollen or extra petal particles; added sounds off by default.
- Complete broader play-testing before the stable 1.0.0 release.

Distant Horizons remains a future possibility, separate from the core release requirements.

These features are planned and are not included in the current development build.
